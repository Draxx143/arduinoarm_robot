# 🦾 کنترل‌پنل اختصاصی بازوی رباتیک ۵ محوره

یک GUI کامل و مدرن برای فریم‌ور `RobotArm_Firmware.ino` — بدون نیاز به نصب هیچ برنامه‌ای!

![tabs](https://img.shields.io/badge/تب‌ها-7-blue) ![commands](https://img.shields.io/badge/پوشش%20دستورات-100%25-green)

## 🚀 اجرا

### روش ۱ — اتصال مستقیم به آردوینو (پیشنهادی)
1. این پوشه را دانلود کن
2. فایل `index.html` را دابل‌کلیک کن (یا با **Chrome / Edge** باز کن)
3. آردوینو را با USB وصل کن (فریم‌ور آپلود شده باشد)
4. روی **«🔗 اتصال به آردوینو»** بزن و پورت COM مربوط به Mega2560 را انتخاب کن
5. باودریت پیش‌فرض `115200` است (مثل Serial.begin در فریم‌ور)
6. اول **«🏠 هوم»** را بزن تا محورها کالیبره شوند ✅

> 🔌 اتصال از طریق **Web Serial API** انجام می‌شود؛ یعنی مرورگر مستقیم با آردوینو حرف می‌زند و به هیچ نرم‌افزار اضافه‌ای (Python، Node، درایور…) نیاز نیست.

### روش ۲ — شبیه‌ساز (بدون سخت‌افزار)
دکمه‌ی **«🎛 شبیه‌ساز»** را بزن. یک شبیه‌ساز کامل از فریم‌ور داخل مرورگر اجرا می‌شود:
هومینگ ترتیبی، حرکت با پروفایل سرعت، دمو، تایمر، teach، لاگ، خواب خودکار… همه چیز مثل آردوینو واقعی جواب می‌دهد و خروجی‌ها دقیقاً با همان قالب متنی فریم‌ور تولید می‌شوند.

## 📱 بخش‌های GUI

| تب | امکانات |
|---|---|
| 📊 **داشبورد** | کارت وضعیت ۵ محور (زاویه/استپ/هوم/برق/حرکت/اند‌استاپ)، خلاصه سیستم، عملیات سریع |
| 🕹 **کنترل حرکت** | اسلایدر هر محور با محدوده واقعی، حالت درجه/استپ، ارسال زنده، moveall + حالت‌های آماده‌ی دمو، پروفایل سرعت |
| 🧮 **کینماتیک** | IK و FK با پیش‌محاسبه‌ی زنده در مرورگر، پارامترهای لینک‌ها (L1=100، L2=100، L3=50mm) |
| 💾 **حافظه و آموزش** | ۱۰ اسلات savepos/loadpos/clearpos، حالت teach با تایم‌لاین، لیست حرکات دمو |
| ⏱ **زمان‌بند و انرژی** | تایمر با شمارش معکوس، خواب/بیداری/خواب خودکار، برق تک‌تک موتورها، لاگر داخلی |
| 📟 **کنسول** | ترمینال سریال کامل با تاریخچه (↑/↓)، چیپ‌های تک‌کلیک همه دستورات، دانلود لاگ |
| 📖 **راهنما** | مرجع کامل ۳۸ دستور + جدول پیکربندی محورها از Config.h + راهنمای اتصال |

### 🤖 بصری‌ساز زنده (همیشه در سایدبار)
- **نمای بغل**: لینک‌ها، مفصل‌ها، زوایای J2/J3، رد حرکت نوک بازو، بازوی هدفِ شبح‌وار، محدوده‌ی دسترسی
- **نما از بالا**: زاویه پایه J1 با قطاع مجاز ‎±110°‎، چرخش ابزار J5، حلقه‌های فاصله
- چراغ وضعیت روی شاسی با رنگ حالت سیستم (آماده/حرکت/هومینگ/ESTOP)

## ⌨️ کلیدهای میان‌بر
- `Esc` → ⛔ توقف اضطراری (estop)
- `Ctrl+K` → فوکوس روی کنسول
- `↑` / `↓` در کنسول → تاریخچه دستورات

## 📁 فایل‌ها
```
gui/
├── index.html        ← همین را باز کن
├── css/style.css     ← تم
└── js/
    ├── firmware.js   ← آینه‌ی Config.h + پارسر پاسخ‌ها + سازنده دستورات + IK/FK
    ├── serial.js     ← Web Serial API
    ├── sim.js        ← شبیه‌ساز فریم‌ور
    ├── viz.js        ← بصری‌ساز Canvas
    └── app.js        ← منطق UI
```

## 🛡 نکات ایمنی
- دکمه‌ی **STOP** (و کلید Esc) در همه‌ی حالت‌ها در دسترس است
- `stop` طبق فریم‌ور، برق همه موتورها را قطع می‌کند (بازو ممکن است افت کند — مواظب باش)
- قبل از هوم، مسیر حرکت بازو را آزاد کن

## ❓ عیب‌یابی
| مشکل | راه‌حل |
